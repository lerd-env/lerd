# Reference

Lookup material rather than guides. If you are setting lerd up for the first time, start with [Getting Started](/getting-started/requirements) instead.

- [Command reference](/reference/commands) is the complete CLI surface, every command and flag, grouped by what it does.
- [Directory layout](/reference/directory-layout) documents what lerd writes to disk and where, including configuration, certificates, generated Quadlets and per-site state.
- [Architecture](/reference/architecture) explains how the pieces fit, the rootless Podman containers, the Nginx and PHP-FPM layers, the watcher, and the store driven design that keeps frameworks and services out of the binary.

For settings you can change, see [Configuration](/configuration). For contributing changes back, see [Building from source](/contributing/building).

# Contributing to Lerd

Thanks for helping out. The contributing guide lives in the docs, so there is one copy to keep current:

- [Contributing](https://lerd.sh/contributing/) is the overview, including where a change belongs.
- [Building from source](https://lerd.sh/contributing/building) covers the toolchain, the make targets and the checks CI runs.
- [Submitting a pull request](https://lerd.sh/contributing/pull-requests) covers commit style and what a pull request needs before it can merge.

Frameworks and services are YAML, not Go: send those to [lerd-env/frameworks](https://github.com/lerd-env/frameworks) and [lerd-env/services](https://github.com/lerd-env/services). Report security problems privately as described in [SECURITY.md](SECURITY.md).

Questions and ideas are welcome on [Discord](https://discord.gg/5JK54s7xCC) or in [GitHub Discussions](https://github.com/lerd-env/lerd/discussions).
